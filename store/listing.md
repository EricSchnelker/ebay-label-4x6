# Chrome Web Store submission: 4x6 Label Fixer

Copy-paste source for the Developer Dashboard
(https://chrome.google.com/webstore/devconsole). Upload
`eBayLabel4x6-chrome-extension.zip` from the latest GitHub release: that zip
is built and tested by CI and contains only the extension.

## Store listing tab

**Name** (from the manifest): 4x6 Label Fixer for eBay Shipping Labels

**Summary** (from the manifest): Turns eBay's sideways letter-size shipping
label PDF into an upright 4x6 for thermal printers. Runs offline.

**Category:** Tools

**Language:** English (United States)

**Detailed description:**

```
eBay's "print shipping label" PDF comes out as a full 8.5 x 11 letter page with the label turned sideways in one corner. On a 4x6 thermal label printer (Rollo, Zebra, MUNBYN, Phomemo and others) it prints sideways and shrunk.

4x6 Label Fixer turns it into a proper upright 4x6 PDF, automatically:

- Automatic: download your label from eBay as usual. An upright copy, eBay_label_..._4x6.pdf, is saved right next to it. You can close the eBay tab at any time.
- Batch: click the toolbar icon, drop several label PDFs on the page and get them back as one combined multi-page 4x6 PDF, ready to print in one go.
- Exact: the label is moved, not resized, so the barcodes stay exactly as eBay generated them and still scan.

Private by design. Labels contain your buyers' names and addresses, so everything happens inside your browser. Nothing is uploaded, there is no account, and there is no analytics or tracking. Open source: https://github.com/EricSchnelker/ebay-label-4x6

Print the result at "Actual size" / 100%, not "Fit to page", on 4x6 label stock.

Free, with no ads and nothing locked. If it saves you time, there is an optional tip link on the converter page.

Not affiliated with, endorsed or sponsored by eBay Inc. "eBay" is a trademark of eBay Inc.
```

## Privacy practices tab

**Single purpose:**

```
Convert eBay shipping label PDFs, which eBay delivers as a sideways label on a letter-size page, into upright 4x6 PDFs for thermal label printers, automatically when a label is downloaded from eBay or on demand for files the user drops on the extension's page.
```

**Permission justifications:**

- `downloads`: Detects when an eBay shipping label PDF (eBay_label*.pdf) finishes downloading, and saves the converted 4x6 copy to the user's Downloads folder.
- `notifications`: Tells the user when an automatic conversion could not be done, with a click-through to the converter page where they can drop the file instead.
- `storage`: Stores the user's auto-convert on/off setting and one line describing the last auto-convert attempt. Uses session storage to hold a just-created label PDF until its download completes (memory only, at most 2 hours).
- `scripting`: Fallback only. If eBay's page created the label before the extension was running, this reads that label's in-page (blob:) PDF back from the eBay tab that made it. Used only on eBay pages, and only for a label the user just downloaded.
- `https://*.ebay.com/*` (host permission): eBay's print page builds the label PDF inside the page, so a content script on eBay pages copies the label PDF when the page creates it. The same permission lets the extension re-read a label the user downloaded from an eBay URL. No other site is accessed.

**Are you using remote code?** No. All JavaScript ships in the package; the
only library is pdf-lib 1.17.1, vendored. The extension pages run under the
CSP `script-src 'self'`.

**Data usage** (what to tick in the dashboard):

- Personally identifiable information / Website content: the extension
  *processes* label PDFs (which contain names and addresses) **locally** to
  convert them. Per the dashboard's definitions, data handled only on the
  user's device and never transmitted is not "collected". Leave the
  collection boxes unticked, and if the form requires an answer for website
  content, say it is processed locally and not transmitted.
- Certify all three: data is not sold to third parties; not used or
  transferred for purposes unrelated to the single purpose; not used or
  transferred to determine creditworthiness or for lending.

**Privacy policy URL:**
https://github.com/EricSchnelker/ebay-label-4x6/blob/main/PRIVACY.md

## Before each new version

1. Bump `version` in `extension/manifest.json` (the store rejects a reused version).
2. Push to main, wait for CI, then run the release (Actions > build > Run workflow, `vX.Y.Z`).
3. Upload that release's `eBayLabel4x6-chrome-extension.zip` under **Package > Upload new package**.
